Branch Manager Permissions

Can:

Add Customer
Edit Customer
Open Account
Approve small loans (depending on your rules)
View Employees
View Branch Reports

Cannot:

Add Branch
Delete Branch
Create Owner
Change Interest Rates
Access Other Branches
View Other Branches' Customers
